This release updates the RainMachine2 plugin for compatibility with Indigo 2025.2 and Python 3.13, while significantly improving stability and simplifying installation.

## Highlights

- No dependencies required (removed regenmaschine / aiohttp)
- Native RainMachine REST implementation
- Improved login reliability (retry logic + startup delay)
- Better error handling and recovery
- Simplified plugin structure

## Result

More stable, easier to install, and no longer dependent on external Python libraries.

This is a drop-in replacement for previous versions.
